# 05 答辩汇报（05_Presentation）

本目录存放汇报 PPT 与逐页讲稿。PPT 为 `飞行器结构设计报告.pptx`（9 页），讲稿如下，可直接作为答辩提示词。

## 逐页大纲与讲稿

### 第 1 页　封面
- 标题：飞行器结构设计分析报告；第十二组大作业汇报。
- **讲稿**：我们组设计的是一型"人机合一"低空个人飞行器——固定翼滑翔型，乘员俯卧挂载、重心移动操纵、双腿起降。下面从结构设计、仿真分析、总结思考三部分汇报。

### 第 2 页　目录
- 01 结构设计 / 02 仿真分析 / 03 总结思考。
- **讲稿**：汇报分三块：先讲结构设计怎么从需求推出来，再讲网格、应力、气动三方面仿真校核，最后是总结与反思。

### 第 3 页　结构设计（章节页）
- **讲稿**：结构设计的核心结论是——低失速（双脚软着陆）强制出大翼面积 20 m²、低翼载、高展弦比 8.45；主梁按 +6g 机动极限设计；人体用大面积躯干托板传力。

### 第 4 页　网格划分
- 内容：RevN / RevP 两版网格参数对比表（全局 18 mm / 最小 3.6 mm，Frontal-Delaunay；RevN 36 万面 / RevP 130 万面）。
- **讲稿**：RevN 只含后翼盒，用于结构；RevP 补齐外形到全弦长，用于气动。两版载荷同源，都来自同一套升力线分布。

### 第 5 页　应力分析
- 内容：6g 工况下主梁沿展向的弯矩、缘条应力、安全裕度 MS 与挠度表（根缘条 364 MPa，MS=0.10；翼尖挠度 0.41 m，6.3% 半展长）。
- **讲稿**：6g 极限下根缘条应力 364 MPa、许用 400，MS=0.10，刚好达标；腹板剪应力仅 ~3.3 MPa。翼尖挠度 0.41 m，属柔性大展弦比翼的正常水平。

### 第 6 页　气动仿真 —— 极曲线与展向载荷
- 内容：阻力极曲线表（α / CL / CDi / CD / L/D）与展向载荷对比。
- **讲稿**：升力线方法给出最大升阻比 22.8，巡航点 L/D≈22.7、下沉率 0.66 m/s；展向载荷与 Schrenk 分布吻合。

### 第 7 页　气动仿真 —— 表面压力云图
- 内容：Cp 云图（上 / 下表面）。
- **讲稿**：Cp 云图显示前缘吸力峰、弦向压力恢复与翼尖卸载，趋势正确；注意这是势流解析场，不含粘性分离与失速。

- 内容：结构设计 / 仿真分析 / 总结思考。
- **讲稿**：进入总结部分。

## 答辩要点备忘

- **贯穿主线**：低失速 → 低翼载 → 大翼面积 → 高展弦比 → 阵风 / 颤振成为瓶颈 → D-box 抗扭 + 限制强阵风高速飞行。
- **人机合一三件事**：人体是结构传力链的一环；人体质量参与重心移动操纵；双腿即起落架。
- **方法边界（主动说明，避免被质疑）**：气动是升力线 / 势流（非 RANS），结构是盒型梁理论（非壳单元 FEA）；更真实结果可把 `03_FEA/mesh/*.stl` 导入 STAR-CCM+/Fluent 或 Abaqus/ANSYS。

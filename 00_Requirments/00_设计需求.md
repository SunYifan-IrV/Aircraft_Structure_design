# 00 设计需求定义 —— “人机合一”低空个人飞行器（结构设计）

设计一型“人机合一”低空个人飞行器的**结构**，使乘员“像鸟一样自由飞翔”，实现：

1. 乘员与结构**高度耦合**（人体不是乘客，而是结构-传力-操纵链中的一环）；
2. 结构**既承受气动载荷，又通过明确的传力路径把载荷传到人体**；
3. 乘员自身质量参与重心控制（“人机合一”操纵），人体双腿兼做起落装置；
4. 飞行高度限定在低空空域（一般运行 ≤300 m AGL，热气流翱翔可达 ~1000 m）。

### 0.1 第一性原理给出的硬约束

| 约束 | 推导 | 结论 |
|---|---|---|
| 人体功率不足以维持平飞 | 人体持续肌肉功率 ≈ 250–300 W；而 ~135 kg 全重平飞需 ~1.2 kW（见 §4.1） | **必须有外部能量源**，人力只能作为应急备份或翱翔辅助 |
| 低失速 → 低翼载 → 大翼面积 | `V_stall = √(2W/(ρ·S·CLmax))`；为双脚软着陆需 `V_stall ≈ 8–9 m/s` | 翼载须取 ~65–76 N/m²，翼面积 ~20 m² |
| 高升阻比 → 高展弦比 | 诱导阻力 ∝ 1/AR | 取 AR ≈ 8.5，翼展 ~13 m |
| 能量密度决定续航 | 锂离子 ≈ 220–250 Wh/kg，`E = m·ρ_E` | 3 kWh 电池 ≈ 14 kg，有动力平飞 ~25–30 min |

## 1. 设计对象：固定翼滑翔型 vs 扑翼型

### 1.1 结论

**采用固定翼滑翔型**（刚性机翼 + 乘员俯卧挂载 + 重心移动操纵 + 电推进辅助起飞/续航）。扑翼型经第一性原理比较后**否决**。

### 1.2 第一性原理比较

| 判据 | 固定翼滑翔型 | 扑翼型 | 结论 |
|---|---|---|---|
| 需用功率 | 平飞 `P = W·V/(L/D)`，L/D≈15 → ~1.2 kW | 扑翼存在非定常气动损失与更高的诱导阻力，有效 L/D 低，同等全重需功率约为固定翼 2–3 倍 | 固定翼胜 |
| 人体功率匹配 | 滑翔/翱翔几乎零能量（像鸟借热气流） | 人体 ~300 W 远不足以支持人尺度扑翼平飞 | 固定翼胜 |
| 结构复杂度/可靠性 | 主梁-翼肋-蒙皮静定传力，可预测 | 需往复机构、柔性铰链、气弹-机构强耦合，疲劳与失效风险高 | 固定翼胜 |
| 尺度/雷诺数 | 稳态翼型在 Re≈1–3×10⁶ 效率良好 | 人体尺度扑翼频率/翼载偏离鸟类高效参数区 | 固定翼胜 |
| 操纵性 | 重心移动（weight-shift）直觉、成熟 | 扑翼周期内需实时协调控制，难度大 | 固定翼胜 |
| 与“像鸟飞翔”的契合 | 鸟长途飞行主体即**滑翔/翱翔**，热气流中盘旋完全实现“自由飞” | 扑翼虽形似鸟，但工程代价高 | 固定翼胜 |

### 1.3 “人机合一”在固定翼上的实现（本设计核心）

- **俯卧挂载**：乘员俯卧于翼下，身体纵轴平行于气流，呈鸟的飞行姿态；
- **传力路径**：气动升力 → 机翼主梁 → 挂点 → 载荷传递带 → 人体躯干（骨盆带 + 胸带）→ 反作用于机翼。**人体成为结构链的一环**；
- **重心移动操纵**：乘员自身质量移动即操纵输入，无需分离的操纵面作动器；
- **双腿即起落装置**：助跑起飞、双脚软着陆。

## 3. 飞行任务、速度范围、机翼面积与翼展

### 3.1 飞行任务（设计任务剖面）

低空个人运动/娱乐飞行 + 热气流翱翔：

1. **起飞**：坡地/平地助跑起飞（电推进辅助，见 §4.3）；
2. **爬升**：电推进爬升至 ~300 m（或牵引/热气流盘旋爬升）；
3. **巡航/翱翔**：50–58 km/h 平飞，或借热气流无动力盘旋（“像鸟一样自由飞翔”）；
4. **下降/着陆**：滑翔下降，flare 后双脚软着陆。

续航目标：有动力平飞 ~25–30 min；无动力翱翔续航取决于天气。任务半径 ~20–50 km。

### 3.2 速度范围（由翼载与 CLmax 第一性原理推导）

给定翼载 `W/S` 与最大升力系数 `CLmax`：

- **失速速度** `V_stall = √(2W/(ρ·S·CLmax))`
  - 名义质量（W/S=66.2 N/m²，CLmax=1.5）：**8.5 m/s ≈ 31 km/h**
  - 最大质量（W/S=76.1 N/m²）：**9.1 m/s ≈ 33 km/h**
- **巡航速度**（CL≈0.65）：`V = √(2W/(ρ·S·CL))` ≈ **14–16 m/s ≈ 50–58 km/h**
- **极限速度** V_NE ≈ **25 m/s（90 km/h）**，设计俯冲速度 V_D ≈ 27.8 m/s（100 km/h）

> 速度范围结论：**失速 ~31–33 km/h，巡航 ~50–58 km/h，极限 ~90 km/h**。

### 3.3 机翼面积与翼展（由失速约束推导）

以双脚软着陆为目标取 `V_stall ≤ 9 m/s`（最大质量），`CLmax = 1.5`（带襟副翼的大展弦比刚性翼）：

```
S = 2W_max / (ρ·CLmax·V_stall²)
  = 2×1521 / (1.225 × 1.5 × 9.0²)
  = 3042 / 148.8 ≈ 20.4 m²   →  取 S = 20 m²
```

展弦比取 `AR = 8.5`（诱导阻力与机动性的折中）：

```
b = √(AR·S) = √(8.5 × 20) ≈ 13.0 m
平均气动弦长 MAC = S/b = 20/13 ≈ 1.54 m
```

| 参数 | 符号 | 数值 |
|---|---|---|
| 机翼面积 | S | **20 m²** |
| 翼展 | b | **13 m**（分段折叠，折叠后 ~5–6 m 以便运输） |
| 展弦比 | AR | **8.5** |
| 平均气动弦长 | MAC | 1.54 m |
| 翼载（名义/最大） | W/S | 66.2 / 76.1 N/m²（6.7 / 7.7 kg/m²） |
| 最大升力系数 | CLmax | 1.5 |
| 最大升阻比（估算） | (L/D)max | ≈ 15（滑翔比 15:1） |
| 最小下沉率（估算） | — | ≈ 0.7–0.9 m/s |

## 4. 能量来源、推进方式与起飞方式

### 4.1 能量来源

**第一性原理功率核算**（名义质量 W = 1324 N，L/D = 15）：

```
平飞需用轴功率  P = W·V/(L/D) = 1324 × 14 / 15 ≈ 1.24 kW
电功率（含 ηp=0.75, ηm=0.90, ηc=0.95）≈ 1.9 kW
```

| 选项 | 结论 | 理由 |
|---|---|---|
| 人体肌肉 | **否决为主能源**（仅作应急/翱翔辅助） | 持续 ~300 W ≪ 1.2 kW |
| 锂离子电池 | **主能量源** | ~220–250 Wh/kg；3.0 kWh ≈ 14 kg，有动力平飞 ~25–30 min |
| 氢燃料电池 / 太阳能 | 远期备选 | 当前功率/质量密度与成本不具优势 |

**结论：主能量源为锂离子电池（3.0 kWh，48 V），滑翔/热气流翱翔为“无动力自由飞”模式。**

### 4.2 推进方式

- **后置推进螺旋桨（pusher prop，折叠式）**：置于乘员背部/中央挂架后上方，气流远离人体，滑翔时可折叠减小阻力；
- **电机**：无刷直流，**峰值 5 kW**（爬升用），巡航 ~2 kW；爬升率约 2–3 m/s；
- 推进为**辅助**（起飞/爬升/应急返航），核心飞行模式为滑翔。

### 4.3 起飞方式

| 方式 | 说明 |
|---|---|
| **坡地/平地助跑起飞（主）** | 乘员双腿助跑，电推进辅助缩短助跑距离（逆风/坡度下 ~15–25 m）——人体即起落架，体现“人机合一” |
| 牵引/弹射（备） | 绞盘或母机牵引，用于无坡地热气流翱翔 |
| 着陆 | 滑翔下降 + flare 拉平，**双脚软着陆** |

## 5. 机翼材料候选方案与结构分析主要工况

### 5.1 材料候选方案

材料选型的第一性原理判据：**比强度（σ/ρ）与比刚度（E/ρ）**。

| 材料 | ρ (kg/m³) | σ (MPa) | E (GPa) | 比强度 (10⁵ N·m/kg) | 用途 |
|---|---|---|---|---|---|
| 碳纤维增强环氧 CFRP（单向） | 1550 | ~2000 | ~140 | ~12.9 | **主梁、蒙皮（首选）** |
| 芳纶纤维（Kevlar） | 1440 | ~2900（纤维） | ~70 | ~20 | 载荷传递挂带、抗冲击部位 |
| 铝合金 7075-T6 | 2810 | ~520 | 72 | ~1.85 | 挂架、接头、快拆机构 |
| 铝合金 6061-T6 | 2700 | ~310 | 69 | ~1.15 | 次级接头、蒙皮框 |
| Nomex 蜂窝 / PMI 泡沫夹芯 | ~40–110 | — | — | — | 蒙皮夹层芯材 |
| 不锈钢（螺栓/关键件） | 7850 | ~1000 | 200 | ~1.27 | 关键连接件、挂点螺栓 |

**推荐方案**：
- **机翼主梁**：CFRP 拉挤/卷绕管梁或箱型梁（单向碳纤维，承受弯曲正应力）；
- **蒙皮**：CFRP 预浸料 + Nomex/PMI 蜂窝夹芯（承受扭转剪流与面外气动载荷）；
- **翼肋**：轻质泡沫芯 + CFRP 薄蒙皮；
- **挂点/挂架**：铝合金 7075-T6，接头局部加强；
- **载荷传递带**：芳纶织带（把机翼升力经骨盆带、胸带传给人体）。

### 5.2 “人机合一”传力路径

```
气动升力(翼面分布载荷)
   → 蒙皮剪流 → 翼肋 → 主梁(弯矩/剪力)
   → 中央挂点(集中力)
   → 芳纶挂带
   → 人体躯干(骨盆带 + 胸带，大面积分布接触压力)
   → 人体重量(惯性反力) 闭合传力环
```

人体作为结构环节的设计约束（生物力学限值）：

- 挂带接触压力：舒适 < ~10 kPa，短时 < ~20–30 kPa（避免压迫神经/血管），载荷须分布于骨盆带 + 胸带大面积；
- 过载耐受：俯卧 +G 短时 ~+4g 至 +9g，负 −G ~−2g 至 −3g 短时 → 结构极限载荷取 **+4g / −2g**。

### 5.3 结构分析主要工况（Load Cases）

| # | 工况 | 载荷/过载 | 关键构件 | 说明 |
|---|---|---|---|---|
| 1 | 极限机动 | **+4g / −2g**（安全系数 1.5 → 极限 +6g / −3g） | 主梁、蒙皮 | 主梁弯曲/剪切强度校核 |
| 2 | 垂直阵风 | 9 m/s 阵风 @ V_D（低翼载刚性翼的**支配工况**，未减缓 Δn 可达数 g） | 主梁、蒙皮 | 需按柔性翼/乘员惯性减缓，并限制低空阵风运行条件 |
| 3 | 起飞/着陆冲击 | flare 触地 ~2–3g，经双腿→骨盆→挂带传力 | 挂点、挂带、人体 | “人机合一”特有的经人体传力动载 |
| 4 | 静态挂载 | 1g 悬吊 + 地面搬运 | 挂架、挂带 | 挂点强度与人体接触压力 |
| 5 | 颤振 / 气动弹性发散 | V_D ≥ 1.2·V_NE | 全翼 | 大展弦比柔性翼的弯扭耦合稳定性 |
| 6 | 疲劳 | 反复起降/阵风交变载荷 | 挂点、主梁接头 | 高周疲劳寿命 |
| 7 | 应急坠撞 | 冲击吸能 | 挂架、缓冲结构 | 结构吸能 + 乘员保护 |

**支配工况小结**：低翼载 + 高展弦比使**阵风工况（#2）**与**颤振（#5）**成为刚性翼的设计瓶颈；**起飞/着陆冲击（#3）**是“人机合一”经人体传力路径的独有校核项。

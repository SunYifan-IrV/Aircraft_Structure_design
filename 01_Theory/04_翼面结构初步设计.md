# 04 翼面结构初步设计（翼梁 / 翼肋 / 蒙皮 / 翼根连接）

> 对应任务：**初选翼梁、翼肋、蒙皮和翼根连接的结构形式**
> 设计载荷：极限弯矩 `M_ult = 12881 N·m`、极限剪力 `V_ult = 4562 N`（+6g @ MTOW，见 03 章）
> 计算脚本：`scripts/calc_wing.py`

## 1. 材料与许用值（初选）

| 材料 | 密度 ρ | 用途 | 设计许用（含折减） |
|---|---|---|---|
| 碳纤维/环氧 CFRP 单向 | 1550 kg/m³ | 翼梁缘条（弯曲正应力） | 压缩 400 MPa / 拉伸 900 MPa |
| 碳纤维/环氧 CFRP ±45° 织物 | 1550 kg/m³ | 腹板剪流、蒙皮扭转剪流 | 剪切 60 MPa |
| Nomex 蜂窝 / PMI 泡沫 | ~40–110 kg/m³ | 蒙皮/腹板夹芯 | 抗剪稳定 |
| 铝合金 7075-T6 | 2810 kg/m³ | 挂点/接头/折叠铰 | σ≈520 MPa |
| 芳纶 Kevlar 织带 | 1440 kg/m³ | 人体载荷传递带 | 抗拉 ~2900 MPa（纤维） |

> 压缩许用取 400 MPa（已含长柱/局部屈曲折减系数），单向 CFRP 名义压缩强度 ~1200–2000 MPa；拉伸取 900 MPa（接头与缺口限制）。最终许用值须经试片试验或按 MIL-HDBK-17 取值。

## 2. 结构传力型式（总体）

采用**单主梁 + D-box 抗扭 + 前缘/后缘辅件**的经典滑翔机机翼构型：

```
气动压力(分布)
  → 蒙皮(弯曲/剪流)
  → 翼肋(把分布载荷集中为线载荷)
  → 主梁(弯矩→缘条正应力；剪力→腹板剪流)
  → 翼根连接(集中内力 → 中央承力盒)
```

- **主梁**：盒型梁，位于 ~30% 弦长处（此处翼型厚度接近最大，缘条间距大）；
- **D-box**：前缘蒙皮 + 主梁腹板构成闭室，承担扭转剪流，提供抗扭/抗颤振刚度；
- **翼肋**：把气动压力与扭矩从蒙皮传入主梁，并维持翼型外形。

## 3. 主梁（盒型梁）初选

### 3.1 缘条（承受弯矩）

盒型梁缘条力偶：`M = F·d`，`d` 为上下缘条形心距。取根部 `d_root = 200 mm`（≈ 最大厚度的 71%，缘条靠近蒙皮）：

```
A_cap = M_ult / (d·σ_allow)
      根: 12881 / (0.20 × 400e6) = 161 mm²（受压控制）
      根: 12881 / (0.20 × 900e6) =  72 mm²（拉伸控制）
```

**选定缘条**：上下各一条**单向 CFRP**，定宽 20 mm，厚度随弯矩沿展向递减：

| η | y (m) | d (mm) | M_ult (N·m) | 需 A_cap (mm²) | 缘条厚度 t (mm) |
|---|---|---|---|---|---|
| 0.00 根 | 0.00 | 200 | 12881 | 161 | **8.0** |
| 0.10 | 0.65 | 190 | 10107 | 133 | 6.7 |
| 0.25 | 1.63 | 175 | 6647 | 95 | 4.8 |
| 0.50 | 3.25 | 150 | 2630 | 44 | 2.2 |
| 0.75 | 4.88 | 125 | 551 | 11 | 0.6 |

> 缘条厚度按“台阶递减”制造（如 8→6→4→2 mm 四段），两缘条等强（兼顾 −3g 负过载）。实际可预浸带铺层/拉挤杆实现，铺层方向 0°。

### 3.2 腹板（承受剪力与扭转）

腹板剪流 `τ = V/(d·t_web)`：

```
t_web = V_ult/(d_root·τ_allow) = 4562/(0.20 × 60e6) = 0.38 mm
```

剪切强度仅需 ~0.4 mm，但深 200 mm 的薄腹板易**剪切屈曲**。故采用**夹芯腹板**：

- 两侧各 1 层 ±45° CFRP 织物（每层 0.25 mm）+ 中间 3 mm PMI 泡沫；
- 总厚 ~3.5 mm，剪切屈曲由泡沫夹芯支撑；
- 前后两块腹板 + 上下缘条 + 前缘蒙皮构成**盒型闭室**，共同抗剪、抗扭。

## 4. 翼肋

- **间距 s = 0.45 m**，每侧半翼展 6.5 m → **14 肋/侧**（含根肋/梢肋）；
- 载荷：根部单位翼展升力 `q_root = 610 N/m`（限制），单肋承载 = `610 × 0.45 = 274 N`（限制）/ 412 N（极限）——翼肋载荷很小；
- **构造**：轻质泡沫芯 + CFRP 薄蒙皮（或薄壁成型肋板），开减轻孔，腹板与主梁腹板铆/胶接，外缘与蒙皮胶接；
- 功能：维持翼型、把蒙皮压力传入主梁、兼作襟副翼铰点与后缘支撑。

## 5. 蒙皮（D-box 抗扭）

- **前缘 D-box 蒙皮**：±45° CFRP 预浸料 + 5 mm Nomex 蜂窝夹芯，总厚 ~2 mm，作为主抗扭闭室；
- **后缘蒙皮**：轻质夹芯板（可稍薄），主要承受局部气动压力并维持外形；
- 蒙皮同时提供局部弯曲刚度，把面外压力传给翼肋。

## 6. 翼根连接（与中央承力盒的接口）

翼根处需把 `V_ult = 4562 N`、`M_ult = 12881 N·m` 传入中央结构，并满足**分段折叠（13 m → 5–6 m）**运输需求。

### 6.1 方案：中央承力盒 + 折叠接头

- **中央承力盒（carry-through box）**：翼根部位沿展向连续、贯穿机体的盒型梁段，长 ~1.6 m（两侧各 ~0.8 m），与两侧外段翼梁在**折叠铰点**对接；
- **折叠铰点**位于 `η ≈ 0.12`（y ≈ 0.8 m）处，该处 `M_ult ≈ 10.1 kN·m`、`V_ult ≈ 3.9 kN`（见上表），略低于翼根，便于接头设计；
- **接头形式**：主梁上、下缘条各用一个**柱销（pin）**传正应力（力偶），腹板剪力用**螺栓组/剪切键**传递；折叠时抽出/松开铰销即可转动；
- 折叠后单段长 ≈ 6.5 − 0.8 ≈ 5.7 m，落入 5–6 m 运输包络。

### 6.2 接头零件

- 铰耳/接头：**7075-T6 铝合金**机加件，与 CFRP 缘条胶—螺栓混合连接（连接区加铺层局部增厚）；
- 铰销：高强钢（如 30CrMnSiA / AISI 4130），直径由销剪/耳承压强度校核（`τ_pin ≈ V/(2A)`，在细化阶段定）。

> 翼根连接与中央承力盒是“人机合一”传力链的枢纽，其详细受力与人体挂载见 05 章。

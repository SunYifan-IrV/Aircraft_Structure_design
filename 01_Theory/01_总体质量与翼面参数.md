# 01 总体质量与翼面参数

> 对应任务：**计算飞行器总质量与机翼所需面积；估算翼展、平均弦长和展弦比**
> 输入：`00_Requirments/00_设计需求.md`（已冻结的设计需求）
> 计算脚本：`scripts/calc_wing.py`

## 1. 设计对象与第一性原理约束回顾

本设计为**固定翼滑翔型**个人飞行器：刚性机翼 + 乘员俯卧挂载 + 重心移动操纵 + 电推进辅助。乘员不是乘客，而是结构—传力—操纵链中的一环（“人机合一”）。

三个第一性原理硬约束直接决定总体参数：

| 约束 | 表达式 | 结论 |
|---|---|---|
| 低失速 → 低翼载 | `V_stall = √(2W/(ρ·S·CLmax))` | 双脚软着陆要求 `V_stall ≈ 8–9 m/s` → 翼载 `~65–76 N/m²` |
| 高升阻比 → 高展弦比 | 诱导阻力 `∝ 1/AR` | 取 `AR ≈ 8.5` |
| 能量密度 → 续航 | `E = m·ρ_E` | 3 kWh 电池 ≈ 14 kg |

## 2. 总质量汇总

| 状态 | 质量 (kg) | 重力 (N) |
|---|---|---|
| 空机质量（机翼主结构 30 + 中央挂架 7 + 电推进 6 + 电池 14 + 操纵仪表 2 + 杂项 1） | 60 | 588.6 |
| 名义乘员质量 | 75 | 735.8 |
| **名义起飞质量** | **135** | **1324** |
| 最大乘员质量（结构用） | 95 | 932.0 |
| **最大起飞质量 MTOW** | **155** | **1521** |

> `W = m·g`，`g = 9.81 m/s²`。名义质量用于性能估算，**MTOW 用于强度设计与极限载荷**。

## 3. 机翼所需面积（失速约束反推）

以“双脚软着陆”为目标，限制最大质量下的失速速度 `V_stall ≤ 9 m/s`，配 `CLmax = 1.5`（带襟副翼的大展弦比刚性翼）：

```
S = 2·W_max / (ρ₀·CLmax·V_stall²)
  = 2 × 1521 / (1.225 × 1.5 × 9.0²)
  = 3042 / 148.8
  = 20.43 m²   →  取 S = 20 m²
```

**结论：机翼面积 S = 20 m²。**

对应的翼载：

| 状态 | W/S |
|---|---|
| 名义 135 kg | 1324 / 20 = **66.2 N/m²**（6.75 kg/m²） |
| 最大 155 kg | 1521 / 20 = **76.1 N/m²**（7.75 kg/m²） |

该翼载处于高性能悬挂滑翔机/超轻型滑翔机的典型区间（约 5–9 kg/m²），远低于普通固定翼飞机（约 60–150 kg/m²），这正是“像鸟一样低失速、软着陆”的物理来源。

## 4. 翼展、平均弦长与展弦比

展弦比取 `AR = 8.5`（诱导阻力与机动性/重量的折中；诱导阻力 ∝ 1/AR）：

```
b  = √(AR·S) = √(8.5 × 20) = √170 = 13.04 m  →  取 b = 13 m
```

平均几何弦长：

```
c̄ = S / b = 20 / 13 = 1.538 m
```

### 4.1 平面形状：直线梯形翼（锥度比 λ = 0.5）

需求只冻结了 `S、b`，平面形状需在此确定。为获得接近椭圆的升力分布（低诱导阻力）并保证翼尖结构刚度与抗颤振能力，取**直线梯形、锥度比 λ = c_t/c_r = 0.5**：

```
根弦  c_r = 2S / [b(1+λ)] = 2×20 / (13×1.5) = 2.051 m
梢弦  c_t = λ·c_r = 0.5 × 2.051 = 1.026 m
```

平均气动弦长（MAC，全机气动/重心参考）：

```
MAC = (2/3)·c_r·(1+λ+λ²)/(1+λ)
    = (2/3) × 2.051 × (1+0.5+0.25)/1.5
    = 1.595 m     （位于展向 y = 2.89 m）
```

> 注：需求文档中的 “MAC = S/b = 1.54 m” 实为**平均几何弦长**；梯形翼的真 MAC（1.595 m）略大于平均几何弦长。本设计后续气动/重心均以 MAC = 1.60 m 为参考。

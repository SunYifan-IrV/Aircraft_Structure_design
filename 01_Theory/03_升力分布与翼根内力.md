# 03 升力分布与翼根剪力/弯矩

> 对应任务：**建立升力分布，计算翼根剪力与弯矩**
> 计算脚本：`scripts/calc_wing.py`

## 1. 方法与假设

大展弦比（AR=8.45）梯形直机翼，采用 **Schrenk 近似** 建立展向升力分布——工程上最常用的机翼载荷近似：**局部升力强度取“椭圆分布”与“平面弦长分布”的平均**。它兼顾了椭圆载荷的低诱导阻力理想与梯形平面形状的真实弦长，与升力线理论结果误差通常 <5%，满足初步结构设计精度。

- 半翼展坐标 `η = 2y/b ∈ [0,1]`；
- 椭圆分布等效根弦：`c_ell(η) = c_ell0·√(1−η²)`，其中 `c_ell0 = (4/π)·c̄`（保证与真实平面同面积）；
- 平面弦长分布：`c(η) = c_r − (c_r − c_t)·η`；
- **Schrenk 升力弦长**：`c_sch(η) = ½[c_ell(η) + c(η)]`；
- 单位翼展升力（单侧）：`q(η) = (nW/S)·c_sch(η)`，`nW` 为总载荷（过载×重力）。

> 载荷以**最大起飞质量 MTOW = 155 kg**为基准：`nW = n × 1521 N`。

## 2. 内力积分

单侧外伸段（η→翼尖）的剪力与弯矩：

```
V(y) = ∫_{y}^{b/2} q dy′
M(y) = ∫_{y}^{b/2} q(y′)·(y′−y) dy′
```

翼根（y=0）：

```
V_root = nW/2
M_root = (nW/S)·(b²/4)·∫₀¹ c_sch(η)·η dη
```

解析可得 `∫₀¹ c_sch·η dη = ½[(4/3π)·c̄ + (c_r+2c_t)/6] = 0.668 m`，故：

```
M_root(限制+4g) = (6082/20)×(13²/4)×0.668 = 8587 N·m
```

数值积分（N=2000 段）结果一致。

### 3.1 与纯椭圆分布对照

纯椭圆分布 `M_root = 8389 N·m`；Schrenk 因梯形平面使升力略向外移而增大 2.4%，属合理、偏保守的差异。

升力合力展向位置：`ȳ = M_root/V_root = 8587/3041 = 2.824 m`（**43.4% 半翼展**），略外于椭圆分布的 42.4%。

## 5. 阵风校核（支配工况的量化）

低翼载 + 高展弦比使阵风成为运行包线的**支配约束**（需求 §5.3 #2）。阵风增量：

```
Δn = ρ₀·V·U_de·CLα / (2W/S)          （未缓和，sharp-edge）
```

代入 `W/S=76.1 N/m²`、`CLα=4.92 rad⁻¹`：

| 状态 | V (m/s) | U_de (m/s) | 未缓和 Δn | 缓和后 Δn | 缓和后 n |
|---|---|---|---|---|---|
| V_C | 14.0 | 9 | +5.0g | +1.0g | 2.0g |
| V_D | 27.8 | 9 | **+9.9g** | +2.0g | 3.0g |

**缓和因子（CS-23 类）：**

```
μ_g = 2(W/S)/(ρ₀·c̄·g·CLα) = 1.61
K_g = 0.88·μ_g/(5.3+μ_g) = 0.205
```

结论：

1. **未缓和**时 9 m/s 阵风在 V_D 下 Δn≈10g，远超 +6g 极限——这正是需求文档警告的“未减缓 Δn 可达数 g”；
2. 计入柔性翼/乘员惯性缓和因子 `K_g=0.205` 后，V_D 阵风限制载荷 ≈ **3.0g**，其极限（×1.5 ≈ 4.6g）仍低于机动极限 **+6g**；
3. 因此**主梁仍按 +4g/+6g 机动极限设计**，同时运行包线必须**限制强阵风天气的飞行速度**（实际运行：湍流中 `V ≤ V_C`，避开 V_D 高速俯冲）。

> 颤振/气动弹性发散（需求 §5.3 #5）在大展弦比柔性翼上同样关键，将在 04 章以扭转刚度（D-box）与质量平衡措施初步应对，精确校核在 03_FEA 阶段。

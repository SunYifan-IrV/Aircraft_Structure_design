# 05 中央承力框架与人体传力路径

> 对应任务：**建立中央承力框架与人体支撑的载荷传递路径**
> 计算脚本：`scripts/calc_wing.py`

本设计区别于常规飞机的核心是**人体是结构—传力—操纵链中的一环**。中央承力框架同时承担四件事：

1. 把两侧机翼的升力（剪力/弯矩）汇合、闭合；
2. 把升力经**挂点—芳纶带—躯干托板**传给人体；
3. 以人体重力（惯性反力）闭合整机受力环，并实现**重心移动操纵**；
4. 承载后置螺旋桨推力、及起降冲击（双腿→人体→框架的逆传力）。

## 1. 中央承力框架布局

以翼根为界，中央结构由四部分组成：

| 部件 | 形式 | 功能 |
|---|---|---|
| **中央承力盒**（carry-through box） | CFRP 盒型梁，展向 ~1.6 m，深 ~200 mm | 两侧翼梁汇合，贯通翼根弯矩，是承力核心 |
| **龙骨**（keel） | 铝 7075-T6 管 / CFRP 盒，沿纵向 ~1.8 m | 承载挂点、连接螺旋桨塔与起降/控制接口 |
| **挂点 / 吊带系统** | 7075-T6 挂耳 + 芳纶织带 | 把升力从龙骨传给人体（可调，兼作重心移动机构） |
| **螺旋桨塔（pylon）** | 铝合金管架，后置 | 安装 5 kW 电机 + 折叠螺旋桨，推力传入龙骨 |

布局示意（俯视 / 侧视，乘员俯卧于翼下）：

```
        ┌──────────── 机翼（两侧）────────────┐
        │       中央承力盒(翼根)            │
        │              │龙骨(纵向)          │
        │              ├──挂点(吊带)──┐      │
        │              │            │      │
        │    螺旋桨塔◄──┘        人体躯干(俯卧)
        │              └──挂点(吊带)──┘      │
        └──────────────────────────────────┘
```

## 2. 传力路径（载荷链）

```
气动升力(翼面分布载荷)
   → 蒙皮剪流 → 翼肋 → 主梁(弯矩/剪力)
   → 中央承力盒(两侧翼根弯矩闭合、剪力汇合)
   → 龙骨 → 挂点(集中力)
   → 芳纶吊带
   → 躯干托板(胸板 + 骨盆板 + 大腿支撑，大面积分布压力)
   → 人体躯干
   → 人体重力(惯性反力)  ── 闭合传力环
```

推力路径：`螺旋桨 → pylon → 龙骨 → 中央承力盒 → 机翼`（加速整机）。
起降冲击路径（逆向）：`地面反力 → 双腿 → 骨盆 → 吊带 → 龙骨 → 机翼`。

## 3. 挂点载荷

挂点承受“乘员 + 挂载在其下方构件”的惯性载荷。以最大乘员 95 kg 计：

| 工况 | 过载 | 挂点合力 |
|---|---|---|
| 1g 悬吊 | +1g | 932 N |
| 限制机动 | +4g | 3728 N |
| 极限机动 | +6g | 5592 N |

挂点/吊带强度按极限 **≥ 5592 N** 设计（芳纶织带抗拉 ~2900 MPa，数根织带并联即可满足，安全裕度大）。

## 4. 人体支撑——接触压力校核（关键）

吊带若仅用“胸带 + 骨盆带”窄带，会在高过载下产生不可接受的接触压力（压迫神经/血管）。校核：

| 支撑形式 | 接触面积 | 95kg @ +1g | 95kg @ +4g |
|---|---|---|---|
| 仅胸带 + 骨盆带 | ~0.055 m² | 16.9 kPa | **67.8 kPa ❌** |
| **躯干托板**（胸 + 骨盆 + 大腿） | ~0.25 m² | 3.7 kPa | **14.9 kPa ✅** |

对照生物力学限值（需求 §5.2：舒适 <10 kPa、短时 <20–30 kPa）：

- 采用**大面积躯干托板**（俯卧姿势：胸板 + 骨盆板 + 大腿支撑，贴合体型的成型托板），+4g 时仅 14.9 kPa，落在短时可承受区间；
- 纯窄带方案 +4g 达 67.8 kPa，不可接受，**否决**。

**结论：人体支撑采用贴合躯干的成型托板（芳纶带 + 硬质托板 + 高密度泡棉），把集中力扩散为 <15 kPa 的大面积接触压力。** 这既是舒适性要求，也是把人体安全纳入结构链的先决条件。

## 5. 中央承力盒与龙骨受力要点

- **中央承力盒**：承受两侧翼根弯矩 `M_ult = 12.9 kN·m`（贯通）与剪力 `V_ult = 4.6 kN`（两侧反力），其缘条/腹板尺寸与翼根主梁同级别，沿纵向与龙骨多点连接；
- **龙骨**：纵向梁受挂点集中载荷（≤5.6 kN）与螺旋桨推力（5 kW @ 15 m/s ≈ 330 N，爬升推力约数百牛），截面远小于弯矩承载需求，主要校核挂点局部与弯剪；
- **重心移动操纵**：挂点沿龙骨前后可调（配平），乘员左右/前后移位即改变全机重心相对气动中心位置 → 产生滚转/俯仰力矩。挂点须提供低摩擦的滑动/摆动自由度，同时把操纵反力闭环传入结构。

## 6. 各工况传力小结

| 工况 | 载荷 | 主传力链 |
|---|---|---|
| 1g 悬吊/静态挂载 | 932 N | 吊带—托板—人体 |
| +4g 机动 / 阵风 | 3.7 kN | 蒙皮→翼梁→承力盒→吊带→人体 |
| 起降冲击（flare 触地 2–3g） | ~2.8 kN 经双腿 | 双腿→骨盆→吊带→龙骨→机翼（逆向） |
| 应急坠撞 | 冲击吸能 | 承力盒/托板缓冲 + 乘员保护 |

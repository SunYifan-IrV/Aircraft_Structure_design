# 飞行器结构设计 —— "人机合一"低空个人飞行器

> 第十二小组 · 飞行器结构设计大作业
> 一型低空个人飞行器（固定翼滑翔型）的**结构设计**全流程交付：需求 → 理论 → CATIA 建模 → 仿真校核 → 报告 / 汇报。

## 一句话定位

一根 13 m 碳纤维刚性梯形机翼 + 中央承力盒/龙骨 + 乘员俯卧挂载 + 后置折叠电推进 + 重心移动操纵 + 双腿起降的**无尾飞翼式单人动力滑翔机**。乘员不是乘客，而是结构—传力—操纵链中的一环（"人机合一"）。

## 设计一页摘要

| 项 | 值 |
|---|---|
| 起飞质量 | 名义 135 kg / MTOW 155 kg（空机 60 kg） |
| 机翼 | S = 20 m²，b = 13 m，AR = 8.45，λ = 0.5，MAC = 1.60 m |
| 翼型 | 主翼 Wortmann FX 63-137，翼尖 E387 过渡 + −2° 洗流 |
| 速度 | V_stall 8.5–9.1 m/s，V_C = 15 m/s，V_NE = 25 m/s，V_D = 27.8 m/s |
| 翼根内力（极限 +6g） | V = 4.6 kN，M = 12.9 kN·m |
| 主梁 | CFRP 盒型梁，d = 200 mm，缘条 20×8 mm（根），夹芯腹板 |
| 翼肋 / 蒙皮 | 泡沫夹芯翼肋 @0.45 m（14 肋/侧）；±45° CFRP + Nomex D-box |
| 翼根连接 | 中央承力盒 + 7075-T6 铰耳/销（折叠） |
| 人体支撑 | 躯干成型托板，接触压力 ≤ 15 kPa @+4g |
| 支配约束 | 阵风（缓和后 n≈3g < +6g 机动）、颤振（D-box 抗扭） |

## 关键结论

1. 低失速（8–9 m/s 双脚软着陆）强制出**大翼面积 20 m²、低翼载 ~66–76 N/m²、高展弦比 8.45**；
2. 主梁按 **+4g/+6g 机动极限**设计（翼根 M = 12.9 kN·m），阵风经缓和因子后（n≈3g）不超机动极限，但运行包线须限制强阵风高速飞行；
3. **人体必须用大面积躯干托板（非窄带）**传递载荷，+4g 接触压力 14.9 kPa 才能满足生物力学限值；
4. **中央承力盒**是气动载荷、人体反力、螺旋桨推力、起降冲击四类载荷的汇合枢纽。

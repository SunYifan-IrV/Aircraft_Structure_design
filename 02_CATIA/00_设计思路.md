# 00 设计思路 —— 飞行器应该如何设计

> 本文件回答"**先想清楚，再动手建模**"：在打开 CATIA 之前，先确定这台飞行器是什么、为什么长这样、各部件如何咬合。
> 几何结果见 [`01_三视图.svg`](01_三视图.svg)；逐部件尺寸见 [`02_详细设计描述.md`](02_详细设计描述.md)。

## 1. 一句话定位

这是一台**无尾飞翼式（悬挂滑翔式）单人动力滑翔机**：

> 一根 13 m 的刚性梯形机翼 + 中央承力盒/龙骨 + 乘员俯卧挂载于翼下 + 后置折叠电推进 + 重心移动操纵 + 双腿起降。

它不像一架"有座舱的飞机"，而更像一架**带电动助力的高性能悬挂滑翔机**，只是机翼从柔性伞布换成了碳纤维刚性翼、并把乘员从"吊在吊床上"升级为"俯卧贴合托板、成为结构链一环"。

## 2. 顶层设计决策：为什么长成这样

从需求出发，逐级向下做减法，每一步只保留"必须的"：

| # | 决策问题 | 结论 | 第一性原理依据 |
|---|---|---|---|
| 1 | 固定翼 vs 扑翼 | **固定翼滑翔型** | 人体 ~300 W ≪ 平飞 ~1.2 kW，扑翼有效 L/D 低、结构疲劳风险高（需求 §1.2） |
| 2 | 要不要平尾/垂尾 | **不要（无尾飞翼）** | 用重心移动 + 襟副翼操纵，靠后掠 + 低悬挂质量摆锤效应提供纵/横稳定性，省去尾翼重量与阻力 |
| 3 | 乘员姿态 | **俯卧（prone）** | 身体纵轴平行气流、迎风面积最小、升力直接经躯干托板传入人体（"像鸟"） |
| 4 | 乘员角色 | **结构—传力—操纵链的一环** | 升力→蒙皮→翼肋→主梁→承力盒→挂带→人体→重力反力，闭合传力环 |
| 5 | 动力 | **5 kW 后置折叠电推进（辅助）** | 主能量锂电 3 kWh；核心飞行模式是滑翔/热气流翱翔（无动力"自由飞"） |
| 6 | 起降 | **双腿助跑起飞、双脚软着陆** | 失速压到 8–9 m/s（≈31–33 km/h）即可双脚落地，人体即起落架 |
| 7 | 操纵 | **重心移动（weight-shift）** | 乘员移位即改变全机重心 → 产生滚转/俯仰力矩，无分离作动器 |

**贯穿全设计的一条主线**：低失速（双脚软着陆）→ 低翼载（65–76 N/m²）→ 大翼面积（20 m²）→ 高展弦比（8.45）→ 大展弦比柔性翼带来的阵风/颤振成为结构瓶颈 → 用 D-box 抗扭 + 限制强阵风高速飞行来应对。这条因果链决定了这台飞机所有关键数字。

## 3. 布局设计思路（三大空间关系）

无尾飞翼的成败在于**三个相对位置的协调**，这也是三视图最需要表达清楚的地方：

### 3.1 纵向（x）：气动中心 ↔ 重心 ↔ 推力线

- **气动中心**在 MAC（y=2.89 m，弦向 25% 处）；
- **整机重心**（含俯卧乘员）必须落在气动中心**前方**一小段（静稳定裕度）——靠**挂点沿龙骨前后可调**实现配平；
- **后置螺旋桨推力线**略高于机翼、大致穿过翼-身区，滑翔时桨折叠收在乘员背上方，气流不吹人体。

### 3.2 垂向（z）：机翼 ↔ 乘员的"摆锤"高度

- 乘员俯卧在翼下 ~1.05 m（弦线到躯干中心），**重心远低于机翼升力面**；
- 这种"低悬挂摆锤"既是**滚转/俯仰静稳定性**的来源，也是"人机合一"的物理基础——升力向上拉、重力向下坠、人体居中被传递。

### 3.3 展向（y）：中央承力盒 ↔ 折叠铰点 ↔ 外段翼

- 中央承力盒贯穿翼根 ~1.6 m（±0.8 m），是**气动载荷、人体反力、螺旋桨推力、起降冲击四类载荷的汇合枢纽**；
- 折叠铰点放在 η≈0.12（y=±0.8 m）处，外段 5.7 m 折下后整机收进 5–6 m 运输包络；
- 主梁弯矩从翼根 12.9 kN·m 沿展向递减，缘条厚度按 8→6→4→2 mm 台阶递减。

## 4. 传力路径（这台飞机区别于普通飞机的灵魂）

```
气动升力（翼面分布载荷）
   → 蒙皮剪流 → 翼肋（把分布压集中成线载）
   → 主梁（弯矩→缘条正应力；剪力→腹板剪流）
   → 中央承力盒（两侧翼根弯矩闭合、剪力汇合）
   → 龙骨 → 挂点（集中力）
   → 芳纶吊带
   → 躯干托板（胸板 + 骨盆板 + 大腿支撑，大面积分散压力）
   → 人体躯干 → 人体重力（惯性反力）── 闭合传力环
```

两条逆路径也走同一套结构：
- **推力**：螺旋桨 → pylon → 龙骨 → 中央承力盒 → 机翼（加速整机）；
- **起降冲击**：地面反力 → 双腿 → 骨盆 → 吊带 → 龙骨 → 机翼（逆向）。

> 关键结论（来自 01_Theory §5）：人体支撑**必须用大面积躯干托板**而非窄带——95 kg @ +4g 下，托板接触压力 14.9 kPa（可承受），纯胸带+骨盆带则达 67.8 kPa（不可接受）。**舒适性要求 = 把人体安全纳入结构链的先决条件。**

## 5. 从"想清楚"到"CATIA 建模"的落地顺序

建模不要一上来就画翼型，应按**传力主链**从内到外、从参考几何到实体：

1. **基准几何**：建立机体坐标系 + 关键参考平面（弦线平面、展向平面、纵平面）；
2. **平面形状（俯视轮廓）**：由 S、b、λ 直接定死的梯形翼投影——这是所有三维的"母轮廓"；
3. **翼型截面**：导入/拟合 FX 63-137（根→中段）、E387（翼尖），放样出外段翼；施加 −2° 洗流与 3° 上反；
4. **主梁 + D-box + 翼肋**：沿展向布 14 肋、盒型梁、前缘闭室；
5. **中央承力盒 + 龙骨 + pylon**：贯穿翼根、纵向挂点、后置桨塔；
6. **人体模型 + 躯干托板 + 挂带**：俯卧姿态、贴合托板、可调挂点；
7. **折叠机构 + 电机/桨 + 电池**：铰点、5 kW 电机、折叠桨、3 kWh 电池；
8. **装配与校核**：重心位置、干涉检查、与 03_FEA 的接口（中面/材料属性）。

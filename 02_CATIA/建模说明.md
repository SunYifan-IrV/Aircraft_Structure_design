# 02_CATIA 建模说明（自顶向下参数化 · 整机）

## 0. 自顶向下参数化思路

采用 **“骨架 + 派生”** 的自顶向下结构：在一个主零件内建立 **Skeleton（几何图形集）** 集中存放全部设计参数、全局坐标系与基准平面；所有结构体（Body）均由这些参数/基准驱动。改参数 → 模型自动更新。

```
Part: Aircraft_Structure
├── Parameters         （全部设计变量，见 §2）
├── GS: Skeleton       （坐标系 + 翼肋基准面 + 根/梢翼型截面曲线）
├── GS: WingSurface    （机翼外形曲面：WingRightLoft + WingLeft 镜像）
├── GS: Construction / CentralFrame_Ref / PowerUnit_Ref / HumanSupport_Ref
│                       （各脚本临时基准面，自动生成）
├── GS: Constraints    （HangPoint / LegTouchL,R / PropThrust —— 供 03_FEA 加载）
├── Body: MainSpar / RearSpar / Ribs / Skin          （翼面结构）
├── Body: CentralBox / Keel / KeelStrut / RootHinge  （中央承力框架 + 连接件）
├── Body: Pylon / Motor / Propeller / Battery / ESC  （动力单元）
└── Body: Cradle / Harness                           （人体支撑）
```

## 1. 坐标系与基准定义

采用 CATIA 默认三基准面作为全局基准：

| CATIA 对象 | 含义 | 全局坐标 |
|---|---|---|
| `zx plane`（y=0） | **机身中心面**（对称面） | Y=0 |
| `yz plane`（x=0） | **翼根位置**（根弦前缘平面） | X=0 |
| `xy plane`（z=0） | **根弦平面**（水平基准） | Z=0 |
| 全局原点 O | 翼根·中心线·前缘交点 | (0,0,0) |

坐标轴：**X 弦向后（LE→TE 为正）、Y 展向（右翼为正）、Z 竖直向上**（右手系）。

翼肋基准面：`zx plane` 沿 +Y 偏置（常 Y 平面），间距 450 mm。

## 3. 关键几何：翼梁必须“装进”翼型

翼型是**有弯度**的，其“中厚线”不在弦线上。FX63-137 在 30% 弦处中厚线在 **+0.051·c**，65% 弦处 **+0.0232·c**。翼梁盒必须以该中厚线为中心放置，否则盒底会穿出翼型下表面。

```
主梁截面中心 (30% 弦):  X = 0.30·c(y) ,  Z = 0.051·c(y) + y·tan4°
后梁截面中心 (65% 弦):  X = 0.65·c(y) ,  Z = 0.0232·c(y) + y·tan4°
截面高(深):  d(y) = SparDepthRoot · c(y)/RootChord   (主梁 200→100)
```

`scripts/verify_geometry.py` 已自检：主梁盒在 y=0…6500 全展向**完全落在翼型内**（见 §9.3）。

## 4. 任务 1：全局坐标系与主要基准面（脚本 01）

1. 新建 Part `Aircraft_Structure`；
2. `Parameters` 建 §2.1 参数；
3. 新建几何图形集 `Skeleton`；
4. 以 `zx plane` 沿 +Y 偏置生成翼肋基准面 `Rib_y450 … Rib_y6300`。

## 5. 任务 2：机翼平面形状、翼型截面与外形曲面（脚本 01）

- 根截面：`FX 63-137`（`airfoil/fx63137_loop.csv`），弦长 2051，位于 y=0、z=0，无洗流；
- 梢截面：`E387`（`airfoil/e387_loop.csv`），弦长 1026，位于 y=6500，上反抬升 z=+454.6，洗流 −2°；
- 用 GSD `Point by Coordinates` + `Spline` 生成两条翼型曲线；
- `Multi-Section Surface`（Loft）根→梢，再 `Symmetry` 关于 `zx plane` 得全翼面 `WingRightLoft` + `WingLeft`。

## 6. 任务 3~5：翼面结构、中央框架、动力、人体支撑（脚本 02~05）

### 6.1 翼面结构（脚本 02）

| Body | 内容 | 建模方法 |
|---|---|---|
| MainSpar | 空心盒梁，左右两侧 | 外矩形+内矩形双轮廓草图 Pad（壁厚 3），沿展向 4 段台阶变截面 200→125 |
| RearSpar | 空心盒梁 | 同上，30×80→30×50（台阶 80→50） |
| Ribs | 15 肋/侧（y=0,450,…,6300） | FX63-137 翼型多边形草图 + Pad 3mm（含洗流/上反） |
| Skin | 蒙皮 2mm | `Thick Surface`（WingRightLoft、WingLeft 各加厚 1+1mm） |

> 台阶变截面与 01_Theory/04“缘条 8→6→4→2mm 台阶递减”一致；蒙皮采用双面偏置 1mm+1mm。

### 6.2 中央承力框架与连接件（脚本 03）

| Body | 内容 | 建模方法 |
|---|---|---|
| CentralBox | 中央承力盒，y=−800…+800 | 空心盒梁（160×200，壁 3），对称 Pad |
| Keel | 纵向龙骨管 φ40×3，x=0…1800，z=−250 | 圆环草图 + Pad |
| KeelStrut | 2 根 φ20×2 竖支杆（x=560/670） | 连接中央盒底与龙骨 |
| RootHinge | 翼根折叠铰，每侧 3 处 | 7075-T6 铰耳（矩形板+φ12 销孔）+ φ12 钢销 |

折叠铰位置（y=±800）：主梁上/下缘条各一 + 后梁一，共 **6 处铰**。铰耳位于翼外侧，销穿过耳片伸入中央盒区（折叠时抽出铰销即可转动）。

### 6.3 动力单元（脚本 04）

| Body | 内容 | 位置/尺寸 |
|---|---|---|
| Pylon | 门式管架：2 竖管 + 1 横梁（φ20×2 铝） | 竖管 z=−250…130，横梁 y=−130…130、z=130 |
| Motor | 5 kW 无刷电机 φ140×80 | 中心 (1350,0,200)，沿 X 推力轴 |
| Propeller | 桨毂 φ40 + 2 片梯形桨叶 Ø1500 | 桨盘 x≈1440（后置推进），桨叶在 YZ 面 |
| Battery | 3 kWh/48 V 锂电箱 500×240×100 | 中心 (350,0,−320) |
| ESC | 控制器小箱 150×100×40 | 中心 (1300,0,140) |

> 螺旋桨为**后置折叠式**：滑翔时桨叶可后折减阻（此处按展开状态建模）；推力方向沿 +X（向后），推力路径 `桨→pylon→龙骨→中央盒→机翼`。

### 6.4 人体支撑与约束接口（脚本 05）

| Body / GS | 内容 | 位置/尺寸 |
|---|---|---|
| Cradle | 俯卧躯干托板 1000×400×10 | 中心 (700,0,−460)，贴合体型（简化为平板） |
| Harness | 4 根芳纶挂带 + 挂点吊杆 + 挂点耳环 | 挂带 50×5 竖条；挂点 (500,0,−350) |
| Constraints | HangPoint / LegTouchL,R / PropThrust | 命名点，供 03_FEA 施加边界条件 |

传力路径：`气动升力→蒙皮→翼肋→主梁→中央盒→挂点吊杆→芳纶挂带→躯干托板→人体`。

## 7. 任务 7：装配检查、质量属性与 STEP 导出（脚本 06）

1. **装配检查**：新建 Product 插入 `Aircraft_Structure`，用约束检查翼根对中、折叠铰同轴（主梁上/下铰同轴于 y=±800 同一 X/Z）、挂点在中心面 y=0；
2. **质量属性**：对各 Body 赋材料密度（CFRP 1550、7075-T6 铝 2810、芳纶 1440、钢 7850、锂电等效 ~1170 kg/m³），`Measure Inertia` 检查整机质量；
3. **STEP 导出**：运行 `06_检查与导出.CATScript` 或 `File > Save As > stp`，输出 `Aircraft_Structure.stp` 供 03_FEA 导入。

## 8. 运行方式

CATIA V5 → `工具 > 宏 > 宏…` → 依次运行：

```
01_骨架与机翼外形.CATScript
02_结构件.CATScript
03_中央承力框架与连接件.CATScript
04_动力单元.CATScript
05_人体支撑与约束接口.CATScript
06_检查与导出.CATScript
```

> 脚本为标准 CATIA V5 自动化 API 模板（数值字面量不带 `#` 后缀）。若版本/界面语言有差异导致某特征生成失败，以本文 §4~§7 的手工配方微调对应步骤；几何数值可对照 `scripts/verify_geometry.py` 输出。

### 9.3 几何/质量自检（`scripts/verify_geometry.py`）

运行 `python scripts/verify_geometry.py` 可复现以下关键结论：

- **翼梁装配自检**：主梁盒（中心对齐翼型中厚线）在 y=0…6500 全展向落在翼型内（30% 弦处翼型厚度 281→141 mm，盒高 200→100 mm）；
- **质量预算**：以“实体/空心盒”简化建模得到的整机结构+动力约 150 kg，**高于需求文档的 60 kg 目标**。原因：本模型的蒙皮按实心 CFRP 2mm 计（62 kg）、翼肋按实心翼型板计（26 kg）、主梁按 3mm 壁空心盒计（22 kg）。真实结构采用 **Nomex/PMI 蜂窝夹芯蒙皮 + 轻质泡沫翼肋 + 薄缘条盒梁**，质量可降到 ~60 kg 量级；FEA 阶段（03_FEA）应以薄壁/夹芯等效厚度重算；
- **重心**：含乘员 75 kg 整机质心约 (x≈774, z≈−87)；挂点 (500, −350) 沿龙骨可调，最终配平以重量平衡校核为准。

> 需求文档的 60 kg 空机预算是**夹芯薄壁结构**的合理值；本文 CATIA 实体模型以“外形/接口/传力路径完整”为目标，质量用等效密度在校核时修正。

# 00 CATIA 建模说明（自顶向下参数化）

## 0. 自顶向下参数化思路

采用 **“骨架 + 派生”** 的自顶向下结构：在一个主零件内建立 **Skeleton（几何图形集）** 集中存放全部设计参数、全局坐标系与基准平面；所有结构体（Body）均由这些参数/基准驱动。改参数 → 模型自动更新，符合参数化要求。

```
Part: Aircraft_Structure
├── Parameters  （全部设计变量，见 §2）
├── Geometrical Set: Skeleton     （坐标系 + 基准面 + 平面形状线框 + 翼型截面曲线）
├── Geometrical Set: WingSurface  （机翼外形曲面）
├── Body: MainSpar / RearSpar / Ribs / Skin
├── Body: RootJoint / CentralFrame / HumanSupport
└── （装配检查与质量属性在 Product 中完成，见 §8）
```

## 1. 坐标系与基准定义

采用 CATIA 默认三基准面作为全局基准：

| CATIA 对象 | 含义 | 全局坐标 |
|---|---|---|
| `zx plane`（y=0） | **机身中心面**（对称面） | Y=0 |
| `yz plane`（x=0） | **翼根位置**（根弦前缘所在平面） | X=0 |
| `xy plane`（z=0） | **根弦平面**（水平基准） | Z=0 |
| 全局原点 O | 翼根·中心线·前缘交点 | (0,0,0) |

坐标轴：**X 弦向后（LE→TE 为正）、Y 展向（右翼为正）、Z 竖直向上**（右手系）。

```
        Z ↑ (up)
          │   y=+6500 (右翼尖)
   ┌──────┼──────────────┐
   │  翼根│   机翼半翼展  │→ Y (span)
   └──────┼──────────────┘
  原点O(LE)  X → (弦向后, TE)
```

需在 Skeleton 中创建的基准：
- 翼肋基准面：`zx plane` 沿 +Y 偏置（即常 Y 平面），间距 450 mm → `Rib_y450, Rib_y900, …, Rib_y6300`；
- 主梁/后梁基准线：在平面形状线框上，分别位于 **30% 弦**与 **65% 弦**处。

## 2. 设计参数表（Skeleton/Parameters）

| 参数名 | 类型 | 值 | 说明 |
|---|---|---|---|
| WingSpan | LENGTH | 13000 mm | 翼展 b |
| RootChord | LENGTH | 2051 mm | 根弦 c_r |
| TipChord | LENGTH | 1026 mm | 梢弦 c_t |
| TaperRatio | REAL | 0.5 | c_t/c_r（公式） |
| WingArea | LENGTH² | 20.0×10⁶ mm² | S = (c_r+c_t)/2·b（公式） |
| AspectRatio | REAL | 8.45 | b²/S（公式） |
| Dihedral | ANGLE | 4° | 上反角 γ |
| Washout | ANGLE | −2° | 翼尖洗流 θ |
| SparChordPos | REAL | 0.30 | 主梁站位（%弦） |
| RearSparChordPos | REAL | 0.65 | 后梁站位（%弦） |
| SparDepthRoot | LENGTH | 200 mm | 主梁高（根） |
| SparWidth | LENGTH | 40 mm | 主梁弦向宽 |
| RibSpacing | LENGTH | 450 mm | 翼肋间距 |
| RibThickness | LENGTH | 3 mm | 典型翼肋厚 |
| SkinThickness | LENGTH | 2 mm | 蒙皮厚 |
| CentralBoxSpan | LENGTH | 1600 mm | 中央承力盒展向长 |
| KeelLength | LENGTH | 1800 mm | 龙骨长 |

> 单位以 CATIA 默认 mm 计。派生量（TaperRatio/WingArea/AspectRatio）建议用 `Relations.CreateFormula` 与主参数链接，实现真正参数化联动。

## 3. 任务 1：全局坐标系与主要基准面

1. 新建 Part，命名 `Aircraft_Structure`；
2. 在 `Parameters` 中建 §2 的全部参数；
3. 新建几何图形集 `Skeleton`；
4. 以 `zx/yz/xy` 三默认面为全局基准，在 `Skeleton` 中用 `Plane Offset` 生成翼肋基准面（`zx` 沿 +Y 偏置 450·k）。

## 4. 任务 2：机翼平面形状、翼型截面与外形曲面

### 4.1 平面形状线框（XY 平面草图）

在 `xy plane` 上画平面形状：前缘沿 Y 轴（LE 无后掠），根弦 `RootChord`、梢弦 `TipChord`（梢前缘在 y=6500、x=0），连接前后缘 → 梯形平面。30% 弦、65% 弦两条斜线即主/后梁站位线。

### 4.2 翼型截面（读入 airfoil/*.csv）

- **根截面**：`FX 63-137`（`airfoil/fx63137_loop.csv`），弦长 2051，位于中心面（y=0、z=0），无洗流；
- **梢截面**：`E387`（`airfoil/e387_loop.csv`），弦长 1026，位于 y=6500，**上反角抬升** z=+454.6 mm（=6500·tan4°），**洗流 −2°**（绕展向轴前缘下俯）。

归一化坐标 (x, y) 的展开（y 为厚度方向，即局部 Z）：

```
根:  X = x·c_r ;  Y = 0 ;      Z = y·c_r
梢:  局部 X0 = x·c_t ; Z0 = y·c_t
     洗流(绕Y轴−2°):  X1 = X0·cosθ + Z0·sinθ ;  Z1 = −X0·sinθ + Z0·cosθ
     上反:  X = X1 ; Y = 6500 ; Z = Z1 + 454.6
```

用 GSD：`Point by Coordinates` 逐点生成 → `Spline`（闭合，SetClosing）过全部点，得到两条闭合翼型曲线。

### 4.3 外形曲面（多截面曲面 Loft）

`Multi-Section Surface`：截面 = 根翼型曲线、梢翼型曲线（`AddSectionToLoft`，方向同向），生成右半翼面；再 `Symmetry` 关于 `zx plane` 镜像得到**全机翼外形曲面**。

## 5. 任务 3：主翼梁、后翼梁与典型翼肋

- **主梁（盒型梁）**：沿 30% 弦站位线，从根到梢做**多截面实体**（Multi-sections Solid）：根截面为 40×200 矩形（形心在 30% 弦、厚度中心），梢截面 40×100，脊线取 30% 弦站位线 → 变截面盒梁；
- **后梁**：同法，65% 弦站位，截面较小（如 30×80 → 30×40）；
- **典型翼肋**：在任一翼肋基准面（如 y=900）上用 `Intersection` 取翼面与该面的交线（翼型轮廓）→ 偏置内缩 3 mm → 拉伸（Pad）3 mm 得典型翼肋；其余翼肋用 `Pattern`（矩形阵列，沿 Y，间距 RibSpacing）生成。

## 6. 任务 4：蒙皮与局部加强

- **蒙皮**：对全机翼外形曲面做 `Thick Surface`，厚度 `SkinThickness=2 mm`（内/外方向取向外），得到蒙皮壳；
- **局部加强**：
  - 前缘 **D-box**：前缘蒙皮 + 主梁腹板围成的闭室（建模时前缘蒙皮取稍厚夹芯，或在翼肋间加前缘加强条）；
  - 翼根/折叠接头区加厚：蒙皮在 y≈±800 折叠铰点附近局部增厚/加垫板（局部 `Pad` 补强）。

## 7. 任务 5：翼根连接件与中央承力框架

- **中央承力盒**：展向盒型梁，长 `CentralBoxSpan=1600`（y=−800…+800），高 200 mm，位于根弦 30% 弦站位，连接左右主梁；
- **翼根连接件（折叠铰）**：主梁上/下缘条各一 **7075-T6 铰耳（clevis）+ 柱销（pin）**，后梁一铰；在 y=±800 折叠铰点处建模（简化：带销孔的耳片 + 圆柱销）；
- **龙骨（keel）**：纵向梁（铝管/CFRP 盒），沿 X、y=0、z≈−250，长 1800 mm，连接中央承力盒下方；
- **螺旋桨塔（pylon）**：后上方管架，安装 5 kW 电机/折叠桨（简化杆件 + 电机座）。

## 8. 任务 6：人体支撑与约束接口（简化几何）

- **躯干托板（cradle）**：俯卧承托板，沿 X 约 200–1000 mm、宽 400 mm、贴合体型的弧面（胸板+骨盆板+大腿支撑），置于龙骨下方、重心附近；接触面积 ~0.25 m²（对应 +4g 接触压力 ≤15 kPa）；
- **挂点**：重心处（x≈500、z≈−350）一点/耳环，作为 FEA 载荷施加点；
- **约束接口**：在挂点、双腿触地点、螺旋桨推力点定义**简化约束几何**（点/线/面），供 03_FEA 施加边界条件。

## 9. 任务 7：装配检查、质量属性与 STEP 导出

1. **装配检查**：新建 Product，插入 `Aircraft_Structure`（或左右翼 + 中央件分件装配），用 `约束（相合/接触/偏置）` 检查翼根对中、折叠铰同轴、挂点在中心面；
2. **质量属性**：对各 Body 赋材料密度（CFRP 1550、铝 2810、芳纶 1440 kg/m³），用 `Measure Inertia` 检查：机翼主结构 ~30 kg、中央挂架 ~7 kg、整机空重 ~60 kg（对照 01_Theory 预算）；
3. **STEP 导出**：`File > Save As > 类型选 stp`，或运行 `scripts/03_检查与导出.CATScript`，输出 `Aircraft_Structure.stp` 供 03_FEA 导入。

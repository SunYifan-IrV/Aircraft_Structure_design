# AI 使用声明

> 课程：飞行器结构设计　｜　小组：第十二小组　｜　日期：2026 年 11 月

## 1. 使用工具

本课程作业在完成过程中使用了 AI 辅助工具 **Claude（Anthropic，Claude Code / Claude Opus 5.5）**，用于辅助设计分析、数值计算、脚本编写、文档撰写与图表生成。

## 2. 具体使用范围

| 环节 | AI 协助内容 | 小组成员人工完成 / 复核 |
|---|---|---|
| 需求分析 | 第一性原理推导、功率 / 能量 / 失速约束的整理与表述 | 逐条核对公式、常数与结论 |
| 理论设计 | 总体参数、翼型选择、升力分布、翼根内力、翼面结构初步设计的计算与文字组织 | 手工验算关键公式、确认设计取舍 |
| 数值脚本 | `01_Theory/scripts/calc_wing.py` 与 `03_FEA/scripts/*.py` 的编写与调试 | 运行、检查输出物理合理性 |
| CATIA 建模 | 建模思路、逐部件尺寸规格整理、VBS 脚本辅助保存 | 实际操作 CATIA 完成建模 |
| 仿真分析 | 网格 / 应力 / 气动报告的生成脚本与结果解读 | 复核方法边界、结论与局限 |
| 文档 / 汇报 | Markdown 文档、Word / PPT 内容的组织与草拟 | 逐段审核、修改并定稿 |

## 3. 使用边界与声明

1. 本设计中所有第一性原理公式、工程判据与材料 / 气动数据均来自公开教材、标准与数据库（见 `../04_Report/00_报告补充章节.md` 参考文献），AI 仅用于**组织、计算与草拟**，未生成任何未经核实的事实或数据；
2. 所有关键数值均经小组成员**手工验算**或脚本**复算**确认，AI 输出中的错误已在复核中修正；
3. 设计逻辑、取舍决策与最终结论由小组成员**理解并负责**，AI 未替代设计判断；
4. 报告、汇报与文档的最终内容经小组成员**逐段审核**，并对其正确性负责。

## 4. 署名与责任

本声明由小组成员共同确认：AI 工具仅作为效率辅助，作业的学术观点、计算正确性与最终结论由第十二小组全体成员负责。
